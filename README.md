# Pokémon Competitive Tools
Lightweight browser-based tools for competitive Pokémon play and quick reference.
Includes a card builder, VGC speed chart, and printable type chart.

## Card Builder
- Manually create pokemon and customise them, then print or save them
- Editable image, moves, ability, item, EVs, stats & nature
- Import sets directly from Showdown by pasting the export data into the Pokémon's name field

![Card Builder](images/card-builder.png)

## Speed Chart
- Displays Pokémon speed tiers
- Supports Smogon usage data
- Fully customise how to display the Pokémon
- Designed to be printed for quick reference

![Speed Chart](images/speed-chart.png)

## Type Chart
- Clean printable type effectiveness chart
- Designed to fit on a single A4 page
- Can print or download the pdf

![Type Chart](images/type-chart.png)

## Usage
Open any tool directly in your browser via GitHub Pages:

- [Card Builder](https://dhak0s.github.io/pokemon-tools/card-builder/)
- [Speed Chart](https://dhak0s.github.io/pokemon-tools/speed-chart/)
- [Type Chart](https://dhak0s.github.io/pokemon-tools/type-chart/)
