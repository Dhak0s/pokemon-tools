How to use:
While this chart can be used without competitive data, it becomes much more useful when you load Smogon moveset files to show which speeds are most likely for each Pokémon based on real competitive usage.

Automatic loading:
If this file is hosted, it can automatically load a file called 'latest.txt' from the same directory. This automatic load can be overriden by loading your own files. You can combine and rename smogon moveset files to create your own latest.txt

Downloading files:
Click the Smogon data site button to navigate to the Smogon moveset directory.
Look for the text files that follow your formats naming convention.

Examples:
gen9vgc2026regibo3-1630.txt
gen9vgc2026regma-1760.txt

Right click on the file and choose "Save link as..." to download it to your device.

Note: It can be useful to dowload multiple files to get a more complete picture, as not all Pokémon are used in every format or rating tier. For example, if you're interested in the Pokémon Champions format, look for files with "regma" in the name, but also consider downloading files from other recent formats and ratings to see a broader range of competitive usage.

Don't know how to read the Smogon file names? Here's a quick guide:
• gen9 = Generation 9 Pokémon (Scarlet/Violet)
• vgc = Video Game Championships, the main competitive format for Pokémon on consoles
• 2026 = The year the stats were recorded
• regma = Regulation M-A, the current ruleset for Pokémon Champions format
• bo3 = Best of 3 format (if this is not present, it is best of 1)
• 1630 = Smogon rating tier (download all the different tiers for a more complete picture (1500, 1630, 1760))

Loading files:
Click Load text files and select the Smogon moveset files you downloaded (you can select multiple files at once).

By default, the chart will show all Pokémon with their full range of possible speeds based on their base stat / nature / max EV / nature & max EV. Once you load competitive data, it will highlight the most commonly used speed spreads for each Pokémon based on the moveset files you provided.

The colors indicate the likelihood of each speed tier based on competitive usage. In order of likelyhood: Green (most likely) → Yellow → Orange → Red (least likely)

Toggles:
• Show Probable Speed Shows the colours for competitive usage
• Only show competitive Pokémon Hides Pokémon that don't appear in the competitive data you loaded
• Only show likely speed Hides all but the most likely speed based on competitive data
• Only show fully evolved Pokémon Hides Pokémon that aren't fully evolved forms
• Separate Megas Keeps Mega forms in their own section; turn off to alphabetize them with everything else
• Order by speed Sorts the Pokémon in order of their base speed stat, rather than alphabetically
• Order by likely speed Sorts the Pokémon in order of their most likely competitive speed, rather than alphabetically

Printing:
This chart is designed to be printed on A4 paper. Click the Print button to open the print dialog. Make sure to set the print scaling to 100% (or "Actual size") to ensure the chart prints correctly. The controls will not be included in the printout.

Note:
The competitive data is based on Smogon's VGC moveset usage statistics, which are updated at the beginning of each month. The chart will show the most likely speeds for each Pokémon based on the moveset files you load, but keep in mind that actual competitive usage can vary and may not be fully captured by the available data. Always consider checking the latest Smogon stats for the most up-to-date information on competitive Pokémon usage and speeds. All pokemon sprites and data are sourced from the official PokeAPI and are accurate as of June 2024.
